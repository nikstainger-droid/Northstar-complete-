# Northstar release checklist

- [ ] Confirm the site opens over HTTPS through GitHub Pages.
- [ ] Add a task, complete it, refresh, and confirm it persists.
- [ ] Add and complete a habit; check today's percentage.
- [ ] Enter a test income and expense; check monthly totals and categories.
- [ ] Import a test CSV and inspect dates, positive/negative signs, duplicate handling and totals.
- [ ] Add a receipt image and confirm it remains after refresh; remove it if storage is tight.
- [ ] Plan a recipe, add its ingredients to shopping, check off an item, refresh.
- [ ] Add a pantry item, cleaning task, project step and note.
- [ ] Export a JSON backup, then test restoring it in a disposable browser/profile.
- [ ] Load the site once online, enable airplane mode, and verify the shell opens offline.
- [ ] On iPhone Safari, test safe-area spacing, forms, dialogs, navigation and Add to Home Screen.
- [ ] Keep a backup outside the device before resetting or clearing browser data.

- [ ] Test bank statement PDF import using a redacted, text-based statement from your bank. Verify dates, descriptions, debit/credit direction, amounts, duplicate handling, and imported totals.
- [ ] Confirm the PDF.js CDN is reachable; PDF reading currently needs internet on first use and is not available for scanned PDFs without OCR.
